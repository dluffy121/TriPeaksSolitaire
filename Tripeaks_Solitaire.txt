Tripeaks solitaire
_______________________

Objective : Create a Tripeak solitaire game using Unity 3D which should playable on mobile devices.


************
Get Unity : Use latest Unity version personal edition, http://unity3d.com/get-unity
************


Game Screen and Rules:
*************************

The game starts with eighteen cards dealt face-down on the tableau to form three pyramids with three overlapping tiers each. Over these three pyramids are ten face-up cards. The arrangement is illustrated as follows:

     O     O     O
    O O   O O   O O
   O O O O O O O O O
  A A A A A A A A A A

  {D} 	{W}

The "O"s in this illustration are the face-down cards and the "A"s are the face-up cards. Arrangement should be dynamic and fit both portrait and landscape mode, with any aspect ratio
{D} = Card Dec
{W} = Waste pile


1. The goal of TriPeaks is to clear as many boards as possible by tapping face-up cards that are either one above or one below the top cards in the Waste pile.
2. Colour and suit do not matter in TriPeaks, you can tap any card on the board as long as it is face-up and is either one above or below the top card on waste-pile
3. Aces can be either high or low in TriPeaks. Try to tap as many cards in the sequence as you can. Here sample sequence Jack, Queen, King, Ace, 2, 3, 2, Ace, King
4. If there are no moves available, provide options to buy new card deck (some randomness of winning condition), 
5. If player exhaust the deck provide option to buy new deck 

Game Controls
*************************
1. Tap a card to match and remove it. ✔️
2. Tap on deck for new card. ✔️
3. Provide hint option (Optional).
4. Scoring system depending on sequence length  e.g ✔️
	a. (Ace, 2, 3, 2, Ace, King, Queen, Joker) = 8 
	b. (2, 3, 4) = 3
5. Mock the purchasing to buy a new deck. ✔️
6. Mock leaderboard data, feed json data to the leaderboard UI to populate it. ✔️
7. Provide some kind of effect for user interaction. 
8. Maintain Highscore and show on UI during the game. ✔️
9. Show game Timer on UI. ✔️
